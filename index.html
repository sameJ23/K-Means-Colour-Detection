K-Means Colour Detection

K-Means Colour Detection is an interactive image processing project that identifies the dominant colours within an image using K-Means clustering. Users can adjust the number of colour clusters, iterations and sampling quality. The image is sampled as RGB colour data before the K-Means algorithm groups similar colours together. The resulting cluster centres are sorted by brightness and displayed as a colour palette alongside the original image.
